# Unit Converter

Convert length, weight, temperature, volume, and speed instantly. Runs entirely in your browser.

**Live:** <https://unit-converter.slippylabs.com/>

## What it does

- Length, weight, temperature, volume and speed, converted live as you type.
- One-click swap to flip the two units around.

## Run it locally

A static site. No build step, no package manager, no dependencies:

```
git clone git@github.com:slippylabs/unit-converter.slippylabs.com.git
cd unit-converter.slippylabs.com
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
